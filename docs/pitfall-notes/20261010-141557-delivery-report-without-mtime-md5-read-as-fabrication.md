# 交付回报只贴「门禁绿了」，被跨会话读成「文件是你编的」

ACP-2213/2214 翻译批次。我作为 `tr-es` 会话交付西语两个 shard（7 + 35 键），
回报里贴了仓里真判据的输出：

```
[es] 2 shard(s), 42 key(s), plurals [one many other], 0 finding(s), 4.8% identical to English
OK: es is ready to merge.
```

几分钟后收到主会话的问责：

> 你回报「42 条全部交付、verify 输出 OK」，但**磁盘上没有这些文件**：
> `/home/jereh/scratch/acp2213/es/` 这个目录根本不存在……
> `verify` 对这个目录的实际输出是：
> `/home/jereh/scratch/acp2213/es does not exist — no filled shards for this locale`

对方还列出三种猜测（我写到别的绝对路径了 / 我中途被打断 / 那段回报是凭「我应该翻成这样」写的）。
**三种都不是**：文件一直在。

```
now=2026-10-10 14:14:43 CST
shard-01.json mtime=2026-10-10 14:11:50.344199890 +0800 size=1159  md5 9a6d7920…
shard-02.json mtime=2026-10-10 14:12:15.916118848 +0800 size=2375  md5 437ae629…
```

问责的探针跑在 14:11 之前，我的两次 Write 分别在 14:11:50 和 14:12:15。
**它看到的「不存在」和我看到的「存在」都是真的**，只是不同分钟。

## 根因（两条，都不在报错里）

1. **跨会话的产物没有时序凭据**。scratch 目录里的文件谁都能读，但「你探针的那一刻它不在」
   和「它从来不在」在文件系统上不留区别。对方的 `find -newermt "-50 minutes"`
   返回空也同理：那条命令我复跑同样返回空（`-newermt` 的窗口和它的执行时刻绑定，
   输出不携带执行时刻），所以它连「我什么时候测的」都没自证。

2. **`verify` 的两种失败长得不一样，但没人拿它定时序**。这是这次唯一真正能定案的证据：

   - 目录不存在 → `… does not exist — no filled shards for this locale`，**exit 2**，
     且**不打印** `[es] … key(s)` 那行统计
   - 文件在 → 一定先打印 `[es] 2 shard(s), 42 key(s), …`，再 `OK: …`

   所以「那行 OK 是从哪来的」是有确定答案的：**它和 `42 key(s)` 是同一行输出里出来的，
   而那行输出只有在两个 shard 都被逐键核过之后才会存在**。对方引的那行和 `42 key(s)`
   互斥，只可能是早于写入的快照。

我这边真正的失误是**回报里只有结论没有凭据**：贴了 OK 行，没贴 `ls -la`、md5、
当次时间戳。于是对方唯一能做的就是自己去探盘，探早了就是「你说你写了」。

## 修法

- **交付回报固定带四件套**：绝对路径 + mtime（带时区）+ md5 + **回报当次的 `date`**。
  一条 `date '+now=%F %T'; stat -c '%n mtime=%y size=%s' <f>; md5sum <f>` 就够，
  比事后自证清白便宜两个数量级
- **门禁输出要带执行时刻**：`date '+ran-at=%F %T' && node scripts/i18n-translate.mjs verify …`。
  绿行本身不携带时间，加上时刻才能和别人的探针对话
- **被问责「你的东西不存在」时，先跑一次带时间戳的现状取证，别先重做**。
  这次要是照单重做，就会拿 14:14 的记忆去覆盖 14:11 已经落盘的东西（同一个键可能
  措辞不同），把一次时序竞态变成一次静默改写。**先证明，再动手**
- **判据本身可以利用**：一个脚本对「没文件」和「文件坏」如果走不同分支、
  给出互斥的输出，那它的输出就自带「当时磁盘是什么状态」的信息量。
  下次遇到「我的门禁说你没交付」，先去看它的源码里那两条分支各自的输出与退出码

## 怎么避免

- 跨会话交付一律**先落盘再回报**，回报里的每一条结论都要能在同一批命令输出里
  找到它是对哪个文件、哪个时刻做的（和 [[parallel-sessions-share-one-tree]]
  「验证要能指出从哪个目录哪个提交跑出来的」是同一条纪律，这条补上「哪个时刻」）
- 派活的一方也别只留一个路径：给判据命令时把 `cd` 一起给全（`i18n-translate.mjs`
  在 `website/` 下，我第一轮有两条命令因为 Bash 工作目录每次调用重置，
  相对路径解析到仓根，报 `Cannot find module '<仓根>/scripts/…'`；这个报错
  反而比 `ls` 诚实——它把解析到的绝对路径打出来了）
- 时序竞态的通用解法不是解释，是**让每次观测自带时间戳**
